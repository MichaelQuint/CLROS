# Step 1734 - Full-byte COM1 FIFO candidate and bounded native inspection

## Summary

Integrate an internal core COM1 hex writer that retains complete sector evidence
and uses bounded bursts only for the standard working 16-byte FIFO identification.
Host checks and the actual Timing EFI publication pass. Bounded native inspection
and the comparison of all other methods pass. Complete native admission and guest
performance measurements remain pending; this is not an accepted optimization.

## Why

Step1732 measured full-sector synchronous serial output as a real cost. Unlike
the rejected copy trial in step1733, this candidate reduces readiness reads by
filling an empty FIFO while preserving every character, ordering and checked I/O.
Actual hardware behavior and repeatable improvement still require original boots.

The helper is internal, with no new public kernel/Linux/OSHost contract, fields,
buffer, cache capacity or persistent FIFO credits. Unknown, broken and other FIFO

enabled; DLAB rejects before output. Initial readiness retains128 polls; subsequent
drain allowances derive from the preceding burst, with total LSR reads capped at
encodedLength*128. The final FIFO drain protects the following ordinary writer.
An output failure invalidates the enclosing record; no prefix is retried or
converted to a successful record. Normal execution requires the existing exclusive
IRQ-off owner. A terminal fault/NMI may take over COM1, abandon output and halt;
normal output never resumes after it.
