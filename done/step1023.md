# Step 1023 - Assemble and authenticate the retained transition code bundle

## What changed and why

`FirstExitCodeBundle` composes the existing vector normalizer, terminal fault
handoff, canonical port-I/O stubs, owned stack entry and permanent CR3
continuation into one three-page caller-owned allocation. The firmware adapter
can now prepare and read back this complete byte layout before publication.

Admission checks exact capacity, alignment, disjoint image/data/state storage,
arena canaries, an executable callback in the original captured image and an
unused fault context before writing. Readback regenerates each component and
compares every byte, embedded context/callback address and unused zero padding.
Only the actual checked port-stub addresses bind the fault reporter; subsequent
preparation is refused. Emission failure consumes the fault context as failed.

The arena reserves its vector page by address; authentication must finish before
entry. Bundle validation does not authenticate descriptor targets or publish RX
permissions. The original arena, context and image must remain stable/exclusive.
