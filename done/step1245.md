## Why

A single child did not exercise the implemented off-stack generation rebind.
R13 now retains a four-cycle counter across syscalls and genuine waits. Each
iteration resets the gate and clear-TID word before clone, verifies distinct
Linux TIDs and inherited masks/TLS, blocks on the original pipe, wakes the
child, and joins through the actual clear-TID exit. Only then can the backedge
create the next lifetime. Stacks, pipe, process and quotas remain unchanged.

The same input requires EINVAL for malformed clone flags, an unaligned futex
and an invalid signal-mask size, EFAULT for an unmapped FS base, and EAGAIN for
clone while both slots are occupied. The quota attempt occurs while the child
is parked and must leave its clear-TID word intact. Parent mask/FS queries,
child inheritance and later genuine TIDs guard retained state.

The parser requires actual slot-two generations one through four and their
successors, monotonically distinct TIDs, the same pipe fds and repeated emitted
RIPs. The timeout still uses one genuine relative millisecond after all child
lifetimes. Original native owner, kernel process, pool and timer code are
unchanged; no new profile or native source admission is introduced.
