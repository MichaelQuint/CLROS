# Step 1098 - Link the disabled bounded rethrow runtime candidate

## Summary

Implement the actual #596 compiler rethrow path and retained-state callbacks,
with a separate default-off project/probe/boot authority and deterministic
linker inputs. Build and publish a disabled NativeAOT candidate. Its linked
bridges and actual method/EH geometry pass limited native checks. Transfer
admission remains false. This is not acceptance and the standard publication
wrapper still rejects the incomplete new source/target contract.

## Why

The previous checkpoints provided generators and predicates. Actual rethrow
must preserve the original exception/root, validate its real inner-catch
capture, unwind the retained original handling context, select the outer
clause, and resume compiler code without reading discarded frames afterward.
