# Step 1098 - Reuse isolated preflight mutation setup

## Summary

The semantic source-contract rejection matrix now uses one isolated source-tree
clone for its 17 single-file mutation vectors. Each vector restores the original
raw bytes in `finally`. Every original producer invocation, rejection assertion
and vector ordering is preserved. No production tooling or runtime code changed.

## Why

The full migration in step1097 reduced the recorded host gate from 93 minutes
28 seconds to 23 minutes 33 seconds, but native fixture setup still dominated.
The preflight fixture copied the complete source inventory once for each
independent semantic mutation. Reusing only this bounded single-file fixture
removes redundant copying without sharing producer results or weakening source
authority. More complex matrices retain separate clones.
