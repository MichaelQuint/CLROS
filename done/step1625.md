## Deferred work

The expert's bounded review says full FIFO reconstruction is unnecessary for the
narrow Progress witness, while fairness/exact ready-queue/spurious-wakeup claims
remain unqualified. Each complete device transaction must uniquely join one
worker/ordinal/wait/request generation across overlapping windows. fd3/fd7 share
one cursor; duplicate data begins after the parent commits8192 bytes and ends at
8200. fd4 positional reads preserve cursor0. Canonical child pread occurs after
parent completion, so it is not evidence of pread progress during the parked
parent read. Device-pending progress additionally needs an actual submit-to-
completion interval; an unreturned syscall alone is insufficient. The program
witness checks endpoints, not an emulated whole user buffer.

The host joins/negative controls are implemented and the Progress route guard is
narrowly connected. Qualify its emitted native/source/ABI/stack closure and a
fresh original parent/device/image/packet/cleanup capture next. CloseReuse and
signal variants remain rejected. Full018 requires its own emitted ABI/stack/
layout review and three fresh A/B/A HTTP/browser captures. No budget increase or
new fixture/harness is authorized by this preparation.
