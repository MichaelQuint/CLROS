New readonly `LinuxSignalMask` is one thread-owned kernel value, not a global
mask or thread identity service. Its evaluator proposes Before/After without
mutating the caller. The future thread/syscall owner serializes user-copy
admission, update and clone publication, and owns actual thread generations.

invalid size/operation with EINVAL, implements block/unblock/set and removes
only SIGKILL/SIGSTOP. Kernel bits for musl's reserved signals 32-34 remain real;
libc filters those at its pthread API. Clone snapshots can be restored or changed
independently. There is no allocation, user access or signal-delivery operation.
