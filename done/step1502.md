- One nullable pipe object retains read/write fd and their original generations,
  plus buffered count. Both ends reserve the existing lowest-free descriptor

  The new pipe never completes the runtime pipe's retained blocking reads.
  Ordinary-file operations cannot borrow the new endpoints. No arbitrary pipe
  byte contents, native cleanup or finite service trailer is inferred.
