## Failures

Early host compilation exposed inaccessible metadata constructors in new
tests; tests now use public decoding/planning factories. A missing test import
was fixed. The first enabled EFI compile exposed managed `ReadOnlySpan` discovery
in the original metadata file; moving only its existing POD types resolved it.
The rejected compile is retained as `virtio-compile-r01.log`.

Independent review found that cached status writes could erase a device failure
raised between feature-register writes and FEATURES_OK. Each advance now reads
and validates the immediately preceding status before writing, with an injected
DEVICE_NEEDS_RESET regression test. The first native publication passed automated
verification but predates this fix and is development-only (`virtio-native-build-r01`).

The staged whitespace check caught a trailing empty line in relocated metadata.
It was removed and its source pin refreshed. Final diagnostic r04 and ordinary
r02 recapture the resulting source closure; PE, COFF and ILC map bytes are
unchanged from the reviewed image.
