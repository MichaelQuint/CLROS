# Step 1269 - Qualified threading packages and sealed instruction admission

## Summary

Implement exact host-side package and instruction admission for step1267's
separate upstream suspension and ThreadPool payloads. Both actual inputs pass;
independent audits reproduce their complete indexes. Sixteen actual-input
tamper controls and 19 focused host checks pass. Hello's original instruction
digest and package contract are preserved. No full-host/native/CLROS QEMU gate
runs. Continue the same eight-issue batch.

## Why

Guest protocol consumers need exact qualified inputs and genuine instruction/
syscall boundaries. An arbitrary ELF, raw opcode scan, same-count forged index
or synthetic output cannot provide that authority. Reuse Hello's existing
decoder algorithm rather than maintain duplicate parsers. Preserve original
apps, producers, Linux evidence and Hello identities.
