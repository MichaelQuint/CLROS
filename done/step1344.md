# Step 1344 - Socket worker protocol and dedicated runner forwarding

## What changed and why

Continue owned #737/#689/#690. Scope comment21722 was posted and read back
before creating QemuTranscripts.NativeAotSocket.cs and its focused controls.
This is an implemented development leaf, not an accepted socket guest batch.

The existing ThreadingProtocol now explicitly admits the two original socket
modes with their sixteen-worker geometry, canonical ELF size and entropy policy.
Its existing memory, syscall instruction/return, signal, generation, ready FIFO,
native transfer, off-stack reap, budget and ownership checks remain in force.
Broader runtime workload-phase requirements remain confined to those workloads.
Production socket validation requires the sealed original program/package and
current relevant sources; the synthetic inspection seam grants no authority.

Source3 epoll waits retain their original port object, maximum event count,
absolute deadline, wait sequence and actual winner. Futex and epoll deadlines
enter the same deadline/order FIFO. An unwon descriptor wait needs a current
watch; DEL and last-close remove eligibility. Known readiness/deadline/signal
winners cannot be replaced. Completion values and actual RESUME must agree;
zero requires a real expired deadline. Stolen readiness reparks the original
deadline with a newer sequence. Prepare-only repark has no fabricated syscall,
CPL3 entry, APIC IRQ or DRAIN. Group cancellation still requires real exit/reap.

The bounded shadow descriptor inventory follows object identity across fd reuse,
shares the existing fd allocation space, and accounts for port borrows after fd
close. The measured socket/epoll syscall surface checks arguments, user mappings,
errors, descriptor ownership and exact outcomes. Each of four accepted connections
must have its original request/reply byte totals, EOF/reset and shutdown behavior
before close. Copied sockaddr/option/event contents are not reconstructed from
pointers: native service checks, original code and future independent packet/peer
evidence remain required. Unmeasured socket operations fail closed.

Native M16_012_POLL records retain actual current identity, table clock, ready
count and whether one outer idle step completed. Zero identity denotes the
supervisor. Poll boundaries preserve deadline releases even without a new syscall;
idle steps count once, separately from active worker transfers. Actual retained
wakes are also observed after CALL/Prepare and before later clock advances, so
an earlier readiness winner cannot be mistaken for deadline expiry. Final
M16_011_CLOSE rows report each actual remaining fd close in ascending order,
including process-static epoll descriptors; the model consumes that exact inventory.

OS.QemuRunner adds --socket-forward-port with decimal1..65535/duplicate checks.
It requires captured modern ARP usernet and rejects the scripted Ethernet peer,
HTTP probe and terminal-fault profiles. It forwards only loopback to the default
usernet guest's port8080. Defaults and existing scripted-peer selection remain.
This runner facility is not yet wired into complete socket orchestration.

## Failures and corrections

Initial synthetic controls caught ambiguous supervisor-versus-worker polling.
The native record now includes the actual current identity, and the model binds
it before selecting or processing that worker. The next synthetic run exposed
an invalid fixture clock advance after group stop; it was corrected to retain
the actual stopped clock, preserving the existing drain check. Final controls
pass. Review also made idle-step counting explicit, avoiding counting multiple
clock observations as multiple native driver steps. Earlier failed focused logs
remain retained and do not supply passing evidence. A bounded independent review
found stale eligibility after watch removal and valid immediate positive-timeout
expiry without a wait. Both were corrected with actual observations and passing
controls. M16_012_EXPIRE binds the original call ordinal, exact native deadline
and post-dispatch clock; missing, mismatched or premature evidence rejects.
The first expiry build warned about fields across partial struct declarations;
the fields now share the primary declaration and the final build has no warnings.
