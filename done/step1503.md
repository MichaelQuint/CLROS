## Implementation

- Root adds a synthetic-only internal callback into the existing web vector.
  The tandem agent writes six signal controls before its three-file piece;
  root writes six readiness controls before the pipe/epoll model, then adds a
  combined directed-signal/recovery integration control. No new agent is spawned.
- Epoll retains the probe read endpoint's original object/generation. Closing
  that endpoint removes its watches before fd reuse; closing the writer retains
  readable EOF/HUP potential. Pipe counts bound possible ready results; socket
  event masks/data remain opaque. This is not copied epoll event/tag evidence.
- An empty live-writer pipe cannot produce a readiness wake. A pipe-only ready
  winner may repark only after the modeled data is gone, retaining deadline and
  increasing sequence. Completion is bounded by current live readiness. The
  existing socket-only bounds remain unchanged.
- Only literal Smoke admits directed signal12. Its pending standard bit
  coalesces; activation35 retains its separate four-entry realtime queue and
  GC proofs. Standard12 wins pending selection before35. A selected delivery
  latches its number, interrupted RSP and proof before an IRQ can obscure the
  first handler CALL; frames retain the selected signal. Scalar rows do not
  directly authenticate siginfo, actions, handler addresses or frame contents.
- New waits and replacement epoll waits recheck unmasked pending signals.
  Existing completion/winner1 is preserved during tgkill. Repark clears that
  winner, publishes the new wait, then pending12 produces winner5/EINTR. Initial
  epoll fields are initialized before the shared staging hook so it cannot
  overwrite that interrupted winner.
- The combined synthetic vector checks write/WAKE1, tgkill12, competing consume,
  empty REPARK/new sequence, WAKE5 while Parking, COMPLETE/RESUME(-4), handler/
  sigreturn restoring -4, then a fresh empty wait and recovery write/complete/
  read. Skipping repark cannot replace the original readiness winner.
