# Step 1102 - Prepare bounded physical-cache page splits

## Summary

Implemented #94's detached 2 MiB leaf split. The helper writes 512 4 KiB
entries into caller-owned storage and returns the prepared parent entry.
Normal/Device/Framebuffer select WB/UC/WC without silent fallback. Only the
requested physical span changes cache policy. The original physical addresses,
permissions and conservative A/D observations survive; PAT bits are re-encoded
at the correct leaf level. Rejection precedes every destination write.

## Why

Mixed cache policy requires splitting a large mapping without accidentally
changing neighboring translations. Reusing the existing strict entry codec
keeps this first implementation small and preserves the existing W^X rules.
