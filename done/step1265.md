# Step 1265 - Integrate pinned Hello protocol, raw output and call continuity

## Summary

Explicit M16-009 Hello admission now composes the exact package/instruction index
with its complete bounded syscall, memory, thread/scheduler, raw output and

Thirty-nine final focused checks pass; the no-stdlib C# closure compiles.
No original native publication, QEMU run or unfiltered full-host suite is run.

## Why

The unchanged app creates Finalizer and SigHandler before stdout. Their real
wait/wake/park/cancel/reap lifetimes cannot be replaced by marker checks. Runtime
paths vary with supported resource/proc views and scheduling, so use bounded
semantic checks rather than one Linux-host syscall count. Actual per-generation
gateway ordinals prevent a missing optional call from silently passing that model.
The existing strict CRLF/32-KiB parser also needs an explicitly scoped larger
Hello envelope and byte-verified treatment of application LF payload data.
