# Step 1508 - Bind race samples to actual-stream HTTP FIFO frames

## What changed and why

Complete the HTTP framing prerequisite for the observed race transport. Logical
attempt IDs and request-write IDs alone cannot bind selected repeated response
bodies to exact HTTP exchanges. The new web-race reader first runs both strict
logical/wire inspectors, then reuses the already-inspected directional-prefix
inventory and bounded HTTP grammar. Quota HTTP admission remains unchanged.
The explicit internal web diagnostic profile additionally frames status600..999;
interim/upgrade/204/304 and close-delimited responses remain unsupported.

Bind each known request interval's original successful write operations to one
exchange ID and expected method/path/Host/POST authorization header/empty body.
Pair response prefixes only by FIFO on the same original stream, retaining all
unselected polls and unsuccessful retries. Persistent requests require the prior
complete response before the next write. No failed attempted-write bytes enter
the known prefix or manufacture a complete request.

Each response outcome must have exactly one complete request/response candidate,
matching status, decoded body bytes and text/plain media type, with original
read end times after request-write start and before exchange end. Failed/canceled
attempts retain incomplete prefixes and may establish only consumed body prefixes
on the final actual write connection. Zero-I/O cancellation has no invented frame.
Selected responses map exact logical exchange IDs to message indices; planned
churn cancellation remains a host event naming its related exchange/index-1.

The report returns copied/read-only directional bytes, offsets, original op IDs,
every request/FIFO response and selected bindings. The transport inspector returns
its already-inspected value internally to avoid reparsing the wire report. All
existing quota public parsers still use their default strict status/header/chunk
contracts. Actual packet/NAT, guest runner/process and source/native ownership are
separate joins.
