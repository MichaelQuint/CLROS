# Step 1061 - Bounded NativeAOT Windows EH clause decoder

## Summary

Implements #579's stateless `NativeAotEhClauseMetadata.ReadClause` operation.
It returns one POD clause only after validating the complete bounded table,
original module/snapshot authority, code and metadata permissions, and the
nearest preceding root for every referenced handler/filter. Errors return no
usable partial clause. No-EH and index misses are distinguished.

## Why

#90 needs actual pinned language-specific metadata before it can select and
execute handlers. The unwind parser supplies listed functions but not EH object
lengths, typed targets or clause ordering. This leaf reads the real format with
an explicit caller-owned compiler-contribution contract; it does not manufacture
ownership from a section tail or execute exception handlers.

## Evidence boundary

Caller bounds are an explicit contract, not proof of compiler provenance.
The stream has a count, not an object byte length. The reader preserves physical
order, empty try-group boundaries, end-exclusive containment and the pinned
permissive 1-5-byte low-bit encoding, including nonminimal widths. It handles
conditional Windows alignment and optional associated-data correctly.

Original image, owner and snapshot must remain mapped and exclusively stable
per call. Typed-prefix admission is not class validation or assignability.
Chains, reverse-PInvoke, unknown flags/kinds, split code and cross-module targets
are unsupported. There is no actual exception dispatch, guest proof or gate
promotion; hosted .NET, Kestrel and cloud readiness remain unestablished.
