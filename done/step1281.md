## Why

The Linux-qualified suspension stress ELF uses private requeue with wake0/move1
at 0x46333e and retries shared requeue at 0x463350 on ENOSYS, then returns without
a wake fallback. Both returned ENOSYS in CLROS. The actual trace returns1 for
one move. The [musl source](https://github.com/ifduyue/musl/blob/v1.2.5/src/thread/pthread_cond_timedwait.c)
and [Linux kernel implementation](https://github.com/torvalds/linux/blob/v6.12/kernel/futex/requeue.c)
confirm the path and actual wake-plus-move return semantics.
