## Summary

The default-off M16-009 application path records four raw HPET readings: before
run-loop validation, immediately before Timer.Arm after TimerInstalled succeeds,
after the initial IRQ capture/stack checks, and after ConfirmSupervisor before
supervisor logging. Failed reads discard the sample. Ordered readings carry the
actual identity, epoch and retained HPET period. They do not advance deadlines,
authorize skipped checks or replace any scheduling/cleanup witness.

Both strict consumers admit one optional M16_008_TIMING record only after an
ordinary completed IRQ supervisor record. Wrong identity/epoch, unordered

## Why

GC stress still fails its unchanged one-second sleep_window. Measuring the
existing path separates setup and return validation from the armed interval
before choosing a change. The armed interval includes gateway/capture work; it
does not establish an APIC frequency or pure user execution time.
