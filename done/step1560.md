## Summary

This is a development checkpoint for the first ten-issue batch (#780, #781,
#782, #768 through #774). It does not qualify the batch or close any issue.
The earlier commits on `codex/nativeaot-fat32-web` retain the deterministic
image/reference publisher and polling block contracts. This checkpoint adds

The actual `static-staged-dev-r05` guest completed 26 external HTTP responses,

## Why

The read milestone needs bounded caller-owned filesystem state and real Linux
file contracts, plus complete upstream middleware evidence before integrating
on-demand disk descriptors. HTTP responses alone cannot establish scheduler,
file, process or device cleanup correctness.
