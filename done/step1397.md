## Changes and purpose

The normal continuing-web runner now requests `/healthz`, `/config`, the logging
exercise, its rejected repeat, `/__clros/vectors`, then final selected health.
The vector entity must contain exactly49152 bytes, byte i=i%251, with SHA256
`664d1e34fe80e8713fefa2b9c30df7d7877bbffd850411ffda14f54bd1ce847c`.
It uses the same owned process and remaining deadline. A wrong byte stops before
later health. Summary/stdout consumers bind the vector URL/method/status/length/
hash/elapsed time and process liveness. The records64 quota case retains its
existing five requests and emits no vector fields.

The anchored packet consumer requires six ordered complete normal streams,
exact binary content type/length/body and bounded segmented/retransmitted data.
Only the vector stream gets its larger response buffer; other bounds remain.
Transport lifetime joins require six normal or five quota connections.

A separate native call checker follows the fifth accepted descriptor until
later health. It requires enough successful response bytes and a native short
send whose returned prefix actually consumes more than one nonempty iovec.
It rejects scalar-only, first-buffer-only, foreign/stale, oversized and incomplete
observations. Full syscall/scheduler/mapping/fd-generation replay and the exact
packet/runner/native/source joins remain mandatory. Continuing captures still
grant no whole-guest cleanup or resource release.

The Linux web qualifier's new v3 receipt retains the original binary response
and observed status/type/length/hash for both default and configured runs. It
also requires the actual app staging line. A staging line or public app send
counter supplies no native vector authority. Historical v2 receipts remain
paired with their original producer; no accepted evidence was rewritten.

Endpoint refusal after owned process-tree termination now uses one bounded
three-second window: successful connections are retried, and only an actual
ConnectionRefused succeeds. A persistently live or unobserved endpoint fails.
