## Implementation

- The tandem agent writes tests before its two bounded implementation pieces.
  ABI adds exact one-byte read/write, immediately captured result/errno, distinct
  original0x5a/recovery0x6b and unchanged cleanup WriteWake. EOF/EAGAIN/short reads
  fail without retry. Pure copied state uses one lock, immutable snapshots,
  monotonic phases/latched IDs and one recovery admission only in phase4.
  Refusals leave every field unchanged. Numeric role IDs are observations,
  never native-thread generation/role authority.
- Root integrates one dedicated actor borrowing both pipe ends. On one release
  it writes the known byte, tgkill12 to the actual waiter and reads exactly that
  byte. These three nonblocking calls are not abandoned after entering due to
  request cancellation. A managed actor Join relinquishes read ownership before
  the waiter may enter a fresh recovery epoll wait. Initial result must be
  EINTR with untouched sentinel, with one actual ThreadPool acknowledgment.
- One copied recovery request makes the request owner write the distinct byte;
  the waiter must return one EPOLLIN/exact tag and read0x6b. No request, early
  ready result, wrong byte, error or timeout can emit `CLROS_SIGNAL_RACE_OK`.
  There is no retry. Bounded scheduling delays and phase flags are intent only;
  original blocked-wait/recheck/repark/signal/sigreturn/consumption/recovery
  ordering remains mandatory for later evidence.
- Cleanup aborts/releases/joins the actor **before reading its Sent flag**,
  covering cancellation between successful tgkill and flag publication. Any
  successful signal waits for native return and callback acknowledgment before
  action drift checks/unregister/exact restoration. Then abort/release/wake/join
  the waiter, restore mask/unchanged alternate stack, dispose events and close
  three descriptors. Unsafe uncertainty exits the owned diagnostic process70.
  Managed joins do not prove prior native pthread tail exit/reap.
- Explicit POST `/__clros/signalrace` shares the old probe's one-shot admission.
  GET `/__clros/signalrace/status` copies phase/IDs only. POST
  `/__clros/signalrace/recover` only sets the once-only stimulus flag; it owns no
  descriptor. All signal POSTs require Content-Length0, exactly one
  `X-CLROS-Signal: v1`, no query and no transfer encoding. Malformed400;
  unsupported501 before native entry; busy/recovery refusal409. The original
  ownership route keeps its response contract; normal health/churn are unchanged.
