## Why

An abandoned read can copy backend sectors into retained filesystem buffers
without copying into user memory. It must retain the exact original inode,
generation, cursor and8192-byte sentinel lease until real CommitExit. A final
pending LBA that merely belongs somewhere in the same file is insufficient:
after k copied sectors, the sole outstanding submit must be sector k of the
exact logical range, with k<16. Completed prep opens may read only independently
classified metadata, not data/sentinel/preserved/unallocated sectors.

The full-profile capture modifier was propagated to the runner but omitted from
RunnerOptions.SerialByteCapacity. The same wrong16MiB property fed live marker
ingestion and final reads. The marker machine rejects a crossing chunk and the
runner terminates QEMU. HTTP can fault before the runner task finishes returning;
the old peer finally joined it but discarded the result. Peer-first completion
does not establish which owner initiated termination.
