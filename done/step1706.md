# Step 1706 - Signal source discovery and writable-disk formatting

## Summary

M16009's two remaining filename-based readers now use the actual EFI compiler
profile and bound declarations. The complete focused M16009 Fast fixture passes.
One writable-disk thread-service file receives token-preserving formatting.
The r68 graph passes 97 focused checks; the final r69 signal refinement passes
13 affected checks. Both runs have unchanged inputs and zero reuse.

## Why

Partial extraction moved boot calls away from EfiEntry.cs. Source spelling,
local names and file placement cannot establish syscall-gate authority. The
new checks locate the actual methods, require the rejecting APIC gate and
ordered signal call, follow callback authentication and retain strict IRQ mode.
Compiler reachability rejects dormant statements; it does not prove that every
runtime path reaches a call or every predicate is true. Runtime observations
remain covered by the independent behavioral/native fixtures.
