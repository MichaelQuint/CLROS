## Why

The expert's bounded closed-failure review identifies six browser framework
GETs on wire, acknowledged without response bytes while metadata reads continue.
The filesystem binds each outstanding read to an operation index/generation.
Only that operation can complete it. The old descriptor pump advances away
from it unconditionally; polling another operation cannot consume the read,
leaves device counters unchanged and ends that ordinary thread turn.

The new tests reproduce missed owner completion, delayed cancellation drain
and missed I/O-error delivery without a VM or new instrumentation. They use
actual retained operations and block counters, not a copy of the selector.
