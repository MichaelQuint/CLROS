# Step 1297 - Reduce repeated native verification work

## Summary

Three bounded changes retain the original native invariants:

- Remove only the run-loop's duplicate saved-code comparison. ReapExited checks
  the same independent53248-byte snapshot at entry, before any reap, scrub,
  rewrite or transfer. The intervening pool audit does not mutate either copy.
  All Observe/Verify/pool audits and other snapshot checks remain.
- StubWriter pads INT3 in complete eight-byte words, then its exact byte tail.
  Uniform0xcc has the same word value in either byte order. Each unaligned x64
  access stays inside the admitted extent. Output-free planning, comparison
  nonmutation, invalid-target rejection and every padding byte are retained.
- CodeBundle.CheckBytes tests code[index]!=0 before the existing pure export
  membership predicates. Export bodies still pass their original comparisons;
  every nonzero byte outside those bodies still rejects. This changes predicate
  order, not accepted bytes or a retained validity lifetime.

The narrow read-only specialist recommendation covers only the first change.
The two local byte/predicate changes follow source inspection and focused checks.

## Why

Step1296 measured substantial supervisor setup and return work around ordinary
IRQ slices. Reducing the timer count alone did not fix the unchanged upstream
GC stress sleep_window. Preserve actual clocks, deadlines and all ownership,
root, capture, stack/code and cleanup checks while reducing redundant work.
