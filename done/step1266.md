# Step 1266 - Mechanical signal interrupted waits and nested alternate stacks

## Summary

Add seven canonical M16-009 mechanical consumers: interrupted pipe/futex
EINTR and SA_RESTART, positive partial-pipe progress, nested alternate-stack
returns and alternate-stack exhaustion. Forty-three distinct focused checks
pass across twelve fixtures, with no reused checks. No full-host suite,
original native publication or QEMU run is performed for this slice.

## Why

Signal host contracts alone do not exercise actual blocked user calls or the
saved context that a handler must return through. Restart must reexecute the
original SYSCALL instruction; a partially completed write must retain its
positive prefix. Nested handlers need independent masks, registers and saved
stack contexts, and stack exhaustion must stop before unchecked handler entry.

## Evidence

Wait tails contain 44 rows for pipe EINTR/restart, 40 for futex EINTR, 41 for
futex restart and 45 for the partial write. All require two generations, six
transfers, two reaps, zero IRQs and exit42. Restarted pipe read consumes the
child's byte; restarted futex sees the child's changed word and returns EAGAIN.
The partial write returns 4096 despite SA_RESTART, compares every prefix byte,
then writes/reads exactly the remaining four bytes without duplicated progress.

Nested return contains 28 actual calls/43 tail rows and two restorers; exhaustion
contains 22 calls/34 rows and no restorer. Handler RSPs are 406c38/4067b8/406338;
the rejected fourth candidate is 405eb8 below the 406000 alternate base. Entry
masks are 1800/3800/7800 hex; handler masks become 3800/7800/f800. Inner/outer
sigreturn restores edited RAX 23456789/12345678 hex. These are constructed bytes
and synthetic protocol controls, not observed guest traces.
