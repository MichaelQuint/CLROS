# Step 1432 - Bounded service transport controls

## Summary

Development only. Implement the service transport-control driver and exclusive
frame injection, driven by original incremental PCAP observations. Twenty fresh
focused checks pass across four fixtures, including real loopback streams with
a synthetic packet producer. No CLROS guest, native or full-host qualification
is added. All seven issues remain open/claimed and the runner guard remains.

## Why

Persist must recover from a lost reopen while another connection progresses;
pending reset must cancel the old handshake before a new SYN on the same tuple.
The ordinary HTTP peer cannot generate those exact faults. Raw injected clients
also need isolation from slirp's automatic resets, without withholding ordinary
HTTP traffic. A single writer avoids overlapping framed writes and keeps every
injection or intentional omission observable.

## Files changed

- `tools/OS.QemuRunner/ServiceSocketControls.cs`: reserve three loopback ports
  until the control task is joined. After the real network gate, reset two
  pending SYN/SYN-ACK exchanges on one tuple with distinct client sequences.
  Start a raw health flow with window0; acknowledge its first one-byte probe
  while retaining window0, record the first positive-window ACK as lost, finish
  healthy traffic on another tuple, then acknowledge the next probe with a fresh
  positive window and require byte-exact HTTP recovery and complete active close.
  Bound active control work to45 seconds and return literal observed packets.

  unique tags. Serialize one pending injection beside unchanged other traffic;

  at most15 minutes; the default five-minute and frame bounds remain.
- `ServicePacketCapture.cs`: bounded synchronous incremental classic-PCAP
  reader; partial input waits, complete records return once, malformed input or
  truncation makes failure sticky, and completion requires exact EOF. Own the
  read-only shared handle until disposal; framing supplies no TCP authority.
- Four matching/updated host fixtures and consolidated workload status.
