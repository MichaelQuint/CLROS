# Step 1317 - Bounded TCP retransmission development

## Summary

Extend the existing retained sender for #152 inside the owned #734 network
batch. The final focused TCP run passes 251 checks across 29 fixtures, including
16 new retry controls. This is host development; #152 remains blocked/open.

## Why

Queued and unacknowledged bytes already have one bounded owner. Add a timer
there, rather than another buffer/controller layer. Timed operation deliberately
keeps one segment outstanding, avoiding speculative congestion-window machinery.

## Files changed

- `src/OS.Kernel/Net/TcpSendWindow.cs`: explicit retained clock/context,
  fixed hard lifetime, bounded retry count and one retransmission per call.
  Only copied TX advances retries; short output/full TX preserves the due timer.
  Retransmit the original unacknowledged extent at SND.UNA using the current
  receive ACK/window; neither SND.NXT nor retained-byte ownership advances.
  Timestamp after accepted TX so callback time cannot shorten the next RTO.
  Commit actual new-send progress even if that later clock observation fails.
  Forward ACK restarts/disarms the timer; duplicate, reordered, invalid and
  window-only ACKs do not postpone it. RTT smoothing uses integer nanoseconds,
  a one-second/configured minimum, at-least-sixty-second cap and Karn exclusion.
  A real timed SYN-ACK retry starts data at at least three seconds, then clean
  data RTT samples can reduce RTO. Clock regression, retry/hard timeout or fatal
  TX retains all backing/attachments until explicit closed scrub/detach.
- `tests/OS.HostTests/TcpRetransmissionTests.cs`: 16 independent controls for
  loss/progress, exact retry wire bytes/checksums, partial/duplicate/reordered
  ACKs, zero windows, short/full/fatal TX, hard/retry timeout, clock overflow/
  regression, copied owners/aliases, sequence wrap, receive progress, RTO cap,
  real handshake retry, post-TX timing and allocation-free warmed loss cycles.
- `TcpSendWindowTests.cs`: expose the existing pure fixture/wire assertion
  internally; add optional actual handshake retry and controlled TX clock advance.
- Existing networking doc and canonical M07-017 evidence only; dependencies,
  labels and desired open state remain unchanged. No EFI/profile/guest edit.
