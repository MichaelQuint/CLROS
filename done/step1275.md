## Files changed

- `apps/NativeAotRuntimeMatrix/NativeAotRuntimeMatrix.csproj`, `Program.cs`:
  C#14/.NET11 workstation-GC app with three in-process rounds. A real earlier
  call throws through a typed filter, catch/rethrow and two finally bodies to
  an outer typed catch with the same exception and checked cleanup order.
- A real explicit static initializer runs once and fails. Six repeated compiled
  accesses require TypeInitializationException with the same original inner
  exception and cumulative attempt counts. No outer-wrapper identity assumption.
- Closed/closure delegates stay live across forced GC; no-inline invocation
  helpers preserve actual delegate calls. Multicast add/remove executes checked
  targets/order/results. This remains ordinary application compiler output.
- Each round starts two fresh dedicated threads, one running and one event-
  waiting, holding live object/interior/TLS roots through two explicit full
  collections. Main roots and continued progress are checked. Both actual joins
  precede success; failed cleanup retains the event if a worker remains live.
  Fresh ThreadStatic state is required only on new dedicated threads. Main TLS
  checks are synchronous, allowing later await continuations to change threads.
- Three unreachable finalizable objects must finalize once, with exact cumulative
  bit masks and no duplicate finalization. GC and finalizer waits require the
  enclosing process owner's independent timeout.
- Each round completes four actual Task.Run results with unique bits/checksum,
  a measured delay, pre-canceled work and canceled live delay, plus a one-shot
  timer's callback/disposal and separate post-drain observation delay. Callback
  and task ThreadPool context, original cancellation tokens, zero stale work
  and complete app-owned teardown are checked. Runtime worker exit is separate.
- `NativeAotRuntimeMatrixGuest.cs`: bounded strict seventeen-row whole output,
  canonical observations/counters, monotonic collection/progress and distinct
  delay/due/drain/observation clocks with stable frequency. File reads use strict
  UTF8 and read-only sharing. No producer, prepared-program or guest authority.
- `NativeAotRuntimeMatrixTests.cs`: independent complete and malformed/missing/
  reordered/stale/overflow/false-root/false-completion/early-clock vectors,
  strict file handling, actual Windows managed matrix plus unchanged original
  runtime regression and invalid arguments. Original package/program selection
  explicitly rejects the unqualified matrix. Canonical app/PAL docs are updated.
