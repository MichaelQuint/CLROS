| --- | --- | --- |
| Program | 0..6 | RX after publication; eight entry/transfer paths |
| Metadata | 7..31 | Supervisor RW/NX, including saved code copy |
| Switch stack | 32..49 | Guards at 32/49, 16 usable pages |
| Eight workers | 50..97 | Six pages each: two guards and four usable pages |
| IRQ stack | 98..103 | Guards at 98/103, four usable pages |

Twenty guard leaves; total 105 pages. Code bytes 28,672, metadata bytes 102,400.
The independent code-region vector covers every program byte exactly once.
Every public retained native component, separately aligned plus a conservative
8-KiB control bound, fits the metadata arena. Original M09 layouts stay separate.
