- `EfiEntry.cs`: larger package thread policy selects eight independent original
  guarded firmware acquisitions before EBS. Each local acquisition revokes its

  reservoir; publication occurs only after all eight succeed. The original

  terminal success. Failed child return also invokes cleanup from its caller;
  unresolved worker/hardware reservations remain owned, never falsely reclaimed.

  checks, partial-copy exposure, short nonblocking exhaustion, invalid pointer
  preflight, suffix overlap/overflow and discard/restart controls.

  callback groups covering eight distinct acquisitions, reentry, discard,
  first/middle/last-block discovery/provider/guard/tail failures and malformed
  alias admission. Existing six original32-byte groups remain intact.
- `EfiContracts.Sources.cs`: reviewed normalized identities for the two changed
  pinned production sources. PAL and EFI docs describe the finite policy.
