  attempts at most32 one-MiB arrays under the already required16MiB GC limit.
  It catches only OutOfMemoryException, verifies every successfully allocated
  array's full pattern, captures actual GC memory/collection values and clears
  all roots in finally. After return and collection, the caller fills/verifies
  fresh2MiB across a collection and emits exact pressure fields. Other failures
  propagate to the existing application failure boundary. No background owner
  or native allocator is added; default v1 does not call this method.
- `tools/OS.Tooling/QemuTranscripts.NativeAotService.Gc.cs`:exact records require
  aligned1..15MiB retained pressure, heap<=committed<=16MiB, positive bounded
  full-collection count and oom=1, alongside the existing later recovery values.
  Missing, malformed, contradictory or unsuccessful pressure records reject.
  The copied value report grants no execution authority.
- `tests/OS.HostTests/NativeAotServiceStartupReplayTests.cs`:independent pressure
  witnesses, boundary acceptance and twelve rejection controls. Existing
  framing/channel/order/budget controls use the extended witness.
- `tools/OS.Tooling/NativeAotServicePublisher.cs`:pin only the reviewed changed
  app file. All five original-source guards remain enforced. Prepared ELF/index
  and source pins in NativeAotServiceProgram stay unchanged until new originals
  exist, so the former ELF cannot acquire authority for the changed app.
- Managed backlog, canonical app/gate docs and this reserved step consolidate
  implemented and unexecuted evidence. The older actual v2 guest is recorded at
