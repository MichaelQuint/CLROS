## Why and changes

NativeAotCurrentSources now expands complete reviewed producer owners, including
the twelve pre-existing NativeAotWebPayload partial files. Paths deduplicate;
conflicting identities and wrong original hashes reject. App-local names such as
Program never merge across projects. Protected producer names remain confined to
reviewed files, including conditional and generated-looking source declarations.

Current app inventory and fixture-copy lists use those expanded inputs. The
shared socket publisher includes the same complete app family in its admission
and before/after publication snapshots. Its exact original-to-current revision is
recorded separately from token-equivalent source moves in ReviewedRevisions.
Compiler recipe, leases, output/native checks and receipt schema are unchanged;
this intentional reader change is not a claim of original producer equivalence.

The five program readers use expanded current inputs under their existing
AuthorityFiles holds. Their original source tables remain intact. ServicePublisher
has only a documentation correction from a fixed file count to the reviewed family;
its complete executable token stream is unchanged. Independent review verifies
37 source-equivalent mappings, one explicit publisher revision, six historical pin
fields and 47 unchanged non-admission Program methods.

Files include NativeAotCurrentSources and its ReviewedFamilies/ReviewedRevisions
partials; Threading/Socket/Containment/Vectors packages; the shared socket fixture
publisher; Web/Service/LogUpload/Sqlite/StaticFile programs; their current-input
fixtures and NativeAotCurrentSourcesTests. No kernel or guest algorithm changes
