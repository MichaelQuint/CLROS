## Why

The host-tested Linux owner must consume actual retained resources and the
qualified kernel thread table without introducing another scheduler. Metadata
uses the existing retained pool pages 4..14; four prepared worker entries have
distinct guarded kernel stacks. The manifest thread quota limits actual table
and process capacity. Initial generation-one descriptors match the fresh table;
later reuse must bind the actual new generation before publication.

Callbacks authenticate the fixed process owner, actual kernel CR3, IF/DF-clear
state and owned CPU envelope. Copy callbacks admit complete retained kernel
extents and preflight user pages. Clear-TID copyout admits its actual switch-stack
local; code, guards and IRQ stack are not bulk-copy buffers. Futex resolution
checks the live user leaf, owned physical backing and real supervisor RW/NX
identity alias. Active FutexCell borrows retain one lifetime; a fresh borrow
after the last cell drains gets a new serial, with overflow refusal. The memory
mutation guard protects retained mappings until those borrows drain.

HPET conversion uses quotient/remainder and checks overflow/regression;
scheduler nanoseconds are never inferred from IRQ epochs. Binding attaches the
existing process, descriptor and mutation-guard owners. Release requires drained
workers/native references and off-stack supervisor state; actual PTE restoration
still belongs to the unfinished driver.

The gateway captures the complete user image before clone/wait dispatch and
retains each worker's blocked call for completion without replay. Transfer admits
the restored descriptor/MSR/root/FP/stack envelope before actual Park/Exit. When
an early wake completes Park in place, an explicit table Yield matches the
emitted supervisor transfer. Gate rejection/call-limit failures stage actual
process shutdown before exit; cancellation during Parking commits the real wait
capture and Yield before the resumed exit drops its retained backing.
