# Step 1485 - Retain original service TCP byte-range timestamps

## Summary

Continue under the same #737 owner and draft PR790. Add a default-null observer
to the existing strict service TCP reader and immutable copied original byte-range
observations. Record only the first appearance of unique stream bytes; exact
retransmissions do not replace original time/record witnesses. QemuSmoke quota
capture remains guarded. No native/app/guest execution occurs.

## Why

The quota peer uses persistent connections. Whole-flow first/last response records
cannot prove a selected exchange's actual interval, and the positive close-based
HTTP reader must not be repurposed as negative capture proof. Preserve original
byte-range observations before a later bounded persistent HTTP/peer/syscall join.
