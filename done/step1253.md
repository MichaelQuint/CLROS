## Why

Native source attachment needs an actual user instruction stream that can fail
when handler entry or complete restoration is wrong. Positive cases block SIGUSR1,
queue it to the real PID/TID, verify no premature handler, then unmask. The real
handler checks signo, SI_TKILL, PID, ucontext flags/saved RSP and stack bounds.
It verifies fresh x87/MXCSR/XMM state and clear DF, edits saved RAX, clobbers RBX/
XMM0, queries the actual mask/alternate stack and writes its own witness before
RET through the user restorer. Parent continuation requires the edited value,
restored RBX/XMM0/x87/MXCSR/DF/FS, intact red zone, one handler, and restored mask/
stack state before its own witness and exit42. Mismatches execute exit_group99.

BadReturn installs saved CS8 (CPL0) and requires actual rt_sigreturn rejection/
owned exit139. BadRestorer registers an unmapped restorer and requires exit139
before handler entry. Their inventories stop at the actual terminal boundary;
they cannot pass by following the unreachable positive parent path.

Only the existing mechanical ELF header/package geometry and bounded instruction
writer are reused internally. All four original M16-008 package hashes remain
identical. The actual syscall15 frame is now copied before gate dispatch replaces
it with the validated return context, so serial evidence retains the real user
restorer instruction/RSP. Other existing syscall records keep their prior policy.
