# Step1153: bounded disk manifest/package/staging host foundation

## Summary

Implement the pure foundation of claimed #130–#133 and shared integration
#631 after accepted FAT step1152. This is development evidence, not acceptance
or closure. A separate default-off live-disk profile remains to be integrated.

## Why

The no-stdlib image has only the reviewed pointer-backed Span surface.
The existing broader host manifest/package parsers use APIs outside that
surface. Keep the new guest-candidate helpers bounded, status-coded and
allocation-free, with independent bytes and the existing host parsers as
differential oracles where their supported contracts overlap.

## Files changed

- `src/OS.Kernel/Storage/NativeManifestDisk.cs`: at most 4,096 ASCII bytes;
  required native v0 fields, optional package/native-aot kinds, strict relative
  app path and source-backed offsets. Environment/listen keys reject.
- `src/OS.Kernel/Storage/APPPKGDisk.cs`: at most 8,192 bytes/16 OSPKGv0 entries,
  range/reserved/metadata/pairwise-overlap/duplicate/path validation, selected
  content offsets and explicit expected repository CRC32. No embedded hash.
- `src/OS.Kernel/Storage/SelectedPayloadOwnedMemory.cs`: revalidate current
  package and selected OSAPPv0 header, then copy the complete payload into
  distinct caller-owned memory, preserving entry offset. Rejection writes
  nothing; source/path/destination range and alias checks are explicit.
- `src/OS.Kernel/Storage/MalformedDiskPackageFailureProbesRemainDiagnosableEBS.cs`:
  pure typed failure metadata conditional on asserted cleanup/canary checks;
  no serial emission or proof of those assertions.
- Shared `Text/AsciiPointerMatcher.cs` and `Memory/BoundedFileSectorCopy.cs`
  under `std/no-runtime/shared`, plus their test files. Sector copies exclude
  final padding and reject counter/source/destination aliases.
- Corresponding four storage test files under `tests/OS.HostTests`.
- `.gitea/backlog/clros-issues.json`, `docs/cstorage.md`, `docs/image-builder.md`,
  `docs/manifest.md`, `docs/nativeaot-nostdlib-limits.md` and this reserved step.

No EFI compile items, boot phases, probe flags or image-builder commands change.

## Failures

The initial host build produced CS8778 for a wrapping-pointer test constant;
an explicit unchecked cast removes the warning without changing the control.
A generated package magic initially encoded backslash-zero instead of the
NUL byte; independent review caught it before focused execution and the exact
8-byte OSPKGv0 magic was repaired.

Repeated `--filter` arguments select only the last fixture. Initial
`package-focused-r01` therefore ran only the two earlier sector-copy checks;
it is retained and excluded from the 29-check qualification. Final per-fixture
runs above select all intended cases. Pairwise-overlap controls now recompute
mutated-package CRC and assert exact overlap/duplicate statuses, preventing a
checksum failure from masking missed range validation. Counter aliases now
reject before writes and the copy loop uses a cached starting offset.
