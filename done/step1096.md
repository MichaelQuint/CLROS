# Step 1096 - C# host runner and shared-contract migration checkpoint

## Summary

Replace module-initializer execution with explicit C# discovery, isolated
fixture workers, aggregate results, runtime filtering, and a fast default lane.
Introduce .NET 10/C# 14 `OS.Tooling`, shared reviewed EFI expectations, a
contract auditor, repository naming/source checks, bounded direct process
execution, and atomic done-step allocation.

This is a partial implementation of the requested all-PowerShell-to-C# plan.
The native build/verifier, QEMU/libvirt, CI/baseline, backlog and remaining
embedded PowerShell migration is not complete or accepted.

## Why

The previous harness ran 439 module initializers before Main; a throwing
initializer prevented later fixtures from running. Runner behavior was copied
across hundreds of files. Repeated EFI compile/source pins and whole-test-file
hashes made unrelated runner changes invalidate integration assertions.

One concrete stale input was independently verified: the unchanged checked-out
OS project has LF bytes (SHA256 `1884e30fbdaa3043f95a26e87e35d1a2b58e401412cbd4c625c84cdd37178657`).
Converting only line endings to CRLF reproduces the retained
`ef6bc679f6411780b5e31fe82ab7651eecbe3785046b35ce9462c514ec384705` pin.
Source-content tests now distinguish that normalization from raw artifact/build
provenance. No production kernel, EFI entry, or probe source was modified.

## Files changed

- `tests/OS.HostTests`: explicit fixture/case attributes, shared assertions and
  runner, build-input manifest, process/runner controls, and migrated naming and
  allocator fixtures. Removed 646 dead registration/helper methods after
  splitting independently runnable cases. Individual boolean assertions carry
  expression/file/line diagnostics; no test vectors were automatically blessed.
- `tools/OS.Tooling`: new C# console project and typed services. The EFI compile
  inventory and diagnostic names are shared; the compile digest derives from
  that inventory. Selected reviewed identity pins are centralized.
- `CLROS.slnx` and the host-test project: include the new host-only tool and
  embed build input hashes, including dependency sources and assemblies.
- Removed `scripts/run-host-tests-focused.ps1` and `scripts/new-done-step.ps1`.
  Filtering compiles the complete test project; reservation uses C# CreateNew.
- Root/test/tool guides, README, documentation map, host requirements, and repo
  audit describe commands, evidence boundaries, and incomplete migration work.
- Existing CI/baseline callers and the workflow explicitly request `--lane full`.
  The default fast lane cannot silently replace their full-host command.
- The heap authority integration case reuses compiled fixture helpers directly;
  it no longer copies another test file into a generated project or strips an
  obsolete initializer attribute. Remaining C# compile/probe count assertions
  consume the shared inventory; independent hardware/ABI numeric vectors remain.

## Failures

- Initial fast run found the old fixed five-tool inventory after OS.Tooling was
  added; later fixtures still ran. The check now compares disk tools against the
  solution's declared host projects, with generated directories excluded.
- The next broader fast run reported three fixtures pinning other test files.
  Those whole-test-file pins and matching dormant cases were replaced with
  registration checks. Production-source/byte checks and the referenced
  behavioral suites remain; their executable tests are not substituted by a
  registration check.
- The initial contract audit reported the CRLF project hash mismatch described
  above. Only semantic source checks were normalized; raw artifact hashes remain
  exact. Other native-only raw pins still require migration.
- The first embedded-manifest target ran after resource-name processing; the
  runner rejected the missing manifest. Moving capture before AssignTargetPaths
  fixed resource inclusion. No missing-manifest bypass was added.
- One migration inventory initially selected only literal-false probe defaults;
  it stopped before writing. It was corrected to enumerate declared probe
  symbol conditions and validate the original 52-name inventory.
- A broad native audit was intentionally terminated before rebuilding its test
  executable. Its partial log (`native-audit-run.log`) is not acceptance evidence.
  No full native run or fresh guest matrix completed in this checkpoint.
