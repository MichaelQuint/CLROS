## Why

The product needs NativeAOT MinimalApi applications serving Blazor assets from
FAT32, then persistent application writes. Existing static-file issues are
read-only. Accepted storage resets/releases its one-sector transport before the
next read, and package descriptors borrow memory rather than accessing disk.
Host parser/tracker defects must not corrupt the new fixture/evidence path.
