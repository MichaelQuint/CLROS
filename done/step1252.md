## Why

Step1251's interrupted waits intentionally refused CurrentImage until a handler
or restart decision completed. Native WorkerPrepare previously tried that borrow
without resolving the decision; the active gateway also lacked pending delivery.
Installing an old completion.Value after delivery would overwrite handler RAX0,
restarted syscall numbers or user-edited sigreturn values. Frame installation
also aliases the captured native syscall frame used by serial evidence.

PrepareUserReturn centralizes actual pending selection/restart resolution and
returns either the final complete borrowed image, actual staged process shutdown,
or rejection. It dispatches no synthetic syscall, changes no gate counters and
executes no user callback. Native hooks run after real Dispatch/CompleteBlocked
accounting and before full user installation. None can include RIP-2/RAX219;
the full image is therefore installed even when no handler remains.

The actual syscall record is copied before installation changes gateway storage.
Fatal delivery preserves its owned exit reason and follows native envelope
restoration, captured CommitExit, supervisor confirmation and off-stack reap.
Signal state is bump-allocated within the existing bounded RW/NX metadata pages,
with exact copy capabilities. Process Release detaches only after real generation
reaps; Signal.End plus a bytewise zero check precede pool restoration/scrub.
Original emitted transition bytes and mechanical package bytes are unchanged.
