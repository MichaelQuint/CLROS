# Step 1123 - Accept retained ACPI selection after firmware exit

## Summary

Accept #95 (M05-002) and shared integration #606 on frozen source
`b5972dae90103ea0d9ebfb2d30dc48f2b245f065`, following implementation in
[step1122](step1122.md). The full host gate passes 4,157 checks across 482 groups.
Fresh QEMU/OVMF captures pass the 83-record selection diagnostic and ordinary
79-record VerifiedExit regression. PR #607 contains the scoped implementation.

## Why

The platform needs a validated view of the original retained MADT, HPET and MCFG
before timer or PCI work. Selection returns retained offsets, never dereferences
embedded physical addresses, and preserves every input byte and descriptor.
