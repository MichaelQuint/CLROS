## Checks and evidence

Artifacts: artifacts/seeded-native-a/native-review. inputs.json pins the exact
COFF, PE, ILC/link maps, managed assembly, linker response and installed LLVM
tools. Existing read-only capture-native.py and extract-methods.py helpers ran
against those pins; capture/result.json and methods/result.json record commands
and hashes. All 577 method bodies, including relocations, match the linked PE.
The unchanged EFI SHA-256 is:
E0DF6450046BA7B241DFA18163D08D4EBBB4772E567F2449B8B1BD228AD010CB.

The existing finite control-flow stack, direct-operand, ABI and PE-unwind analyses
were copied into this ignored review directory and adapted for the new entry and
its terminal rejection helper. Exact scripts and output hashes are pinned by
native-progress.json. Run commands use C:/Python314/python.exe -B with
review-stack.py, review-full-callback-stack.py, review-access.py, review-abi.py,
review-full-unwind.py and review-thunk-root.py from that directory. All pass.

- Seeded entry: 124 reachable methods, maximum 14344 bytes below entry RSP.
- Full GC/churn entry: 169 methods, maximum 15272 bytes; finite acyclic call graph,
  balanced returns/tails and ordinary call alignment checks pass.
- The same-image generated reference thunk bytes/relocations and compiled static
  root/node accesses are re-associated. A conservative additional 448 bytes gives
  15720 bytes, below the existing 16384-byte diagnostic clearance.
- Three read-only jump tables contain 17 entries; unsigned guards and local
  instruction targets are checked on actual bytes.
- ABI analysis checks 18769 register states, 285 restored returns, four restored
  tails and 2473 direct store states against saved nonvolatile registers. XMM6
  preservation passes; other nonvolatile SIMD registers are unused in this graph.
- The actual PE exception directory has 578 records; all 169 rooted method
  records match their decoded frames. This is not exception-execution evidence.
- Direct stack operand analysis covers 3837 states, deepest access 15264 bytes,
  236 bulk calls with constant lengths, and identifies 891 stack-address sites.
  Identification of an escaped address is not complete provenance proof.
- No reachable method contains FS/GS-relative TLS access. The two indirect sites
  are the existing firmware OutputString and SerialWrite calls; their bodies are
  explicitly excluded from first-party depth accounting.

All publication source pins and native/tool input pins were rechecked unchanged.
The instruction comparison, after normalizing relocations/direct-call targets,
finds 567 unchanged, five changed and five new methods relative to the collector
development image; every current method was independently associated regardless.
No repeat publication, QEMU run or full suite was needed. git diff --check passes.

## Failures

The first adapted stack analysis reached the compiler's unreachable INT3 after
NodeReceipt called the existing RejectGc helper: only the new rejection helper
had been classified as nonreturning. The local analysis now verifies both helpers'
actual terminal call to the EB FE spin before excluding their unreachable tails.
No production fix or relaxed runtime condition was required. A raw unwind-text
comparison included changed addresses; the recorded normalized instruction
comparison avoids treating those addresses as semantic method changes.
