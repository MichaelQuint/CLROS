## Implementation

- A default-off `nativeaot web qualify --signal-race --output <fresh-directory>`
  preserves both existing default/configured v4 sessions and runs a fresh third
  owned strace/app session. Its v5 receipt additionally validates that session's
  HTTP/log/vector/race artifacts. Default qualification remains v4. Copied pid
  must match the actual owned tracee before SIGTERM; existing session stop,
  output joins and process-group death checks remain mandatory.
- The HTTP controller owns both pending POST tasks, requests recovery once,
  checks duplicate and one-shot refusals and joins requests before releasing
  their lifetimes. Original churn and race requests must remain pending through
  overlap selection; timer, worker and collection counters must each advance.
  Churn cancellation is observed and server counters drain before recovery.
  A fresh completed eight-operation churn proves later progress. Fresh output
  retains partial/rejected observations on unsupported, lost overlap, stale
  progress, HTTP or caller cancellation failures; there is no retry to success.
- The copied validator checks all19 rows, canonical properties/integers/body
  fields, role consistency, initial EINTR, recovery values, restoration flags,
  counter deltas and exact refusal/health bodies. It returns copied selection;
  it grants no native process, callback-code, byte/event/action content authority.
- Explicit selection initializes a checked original-row map before real web
  replay. Existing program/package/parent admission remains in the production
  path. The projection runs only after the entire scheduler prefix passes.
  Live model hooks retain actual pipe/port/watch generations and selected signal
  frame entry/return; no second scheduler or fd allocator is introduced.
- Immutable output joins actual identities/Tids/FS and mapped original indices
  for write/ready win/tgkill/competing read/repark/interruption/resume/frame/
  sigreturn/fresh recovery and all three explicit closes. Captured native
  EXIT/REAP indices are optional; absence stays null. Original normalized indices
  include removed configuration/logging metadata and are not raw byte offsets.
- The same agent authors four independent projection controls before its two
  files and reviews root's controller/validator/hooks. It finds a missing strict
  counter delta; root fixes both producer selection and copied validation and
  adds stale-counter controls before any build. No extra agent or peer build.
