# Step 1298 - Reuse admitted leaf encodings within user-root operations

## Summary

The unchanged broader GC stress now passes its complete strict guest verifier.
The measured bottleneck was repeated whole-root audits on startup syscalls,
including unsupported mremap and clock calls. Build and Audit now encode the
first leaf once per admitted contiguous range and add aligned physical offsets.
Audit reuses only the last matching range within that synchronous call.

All actual entries still pass exact expected-PTE comparison modulo the original
hardware A/D mask. Range admission, parent encoding/uniqueness, complete table and
leaf counts, extra leaves and unused-table zeroing remain. No validity cache
crosses a callback, mapping mutation, return or later audit invocation.

Optional M16_008_SYSCALL_TIME records expose capture/admission, gateway dispatch
and return preparation using four real raw HPET readings. Initial owner and exact
frame authentication precede the first read and are outside these intervals;
serial logging is also outside them. Failed reads suppress the sample. Both
strict consumers allow one optional record only after its actual generation,
ordinal and syscall, with ordered readings and valid period. These diagnostics
cannot replace calls, waits, IRQs, output or cleanup evidence.
