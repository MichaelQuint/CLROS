## Why

The pinned NativeAOT activation handler may legitimately edit the user context.
Returning only Frame/Value loses edited registers and SIMD state; copying an
immutable old image would discard the runtime's changes. Unchecked sigreturn
would allow hostile control state into IRET/FXRSTOR. The existing actual thread
owner and complete UserImage provide the narrow integration boundary.

Frames use the kernel's 440-byte x64 header, eight-byte mask, fixed selectors,
siginfo and separate 64-byte-aligned 512-byte legacy FX storage. Ordinary stack
delivery preserves the 128-byte red zone. Alternate-stack bounds, autodisarm,
per-handler masks, NODEFER and RESETHAND are real state. One actual generation
owns up to four LIFO frame addresses; clone does not inherit that ownership and
actual reap scrubs it. No kernel pointer is serialized in the frame. Handler
entry clears DF and initializes fresh x87/SSE state after saving interrupted FP.

Syscall15 reads RSP-8 after the restorer return address has been popped. It checks
the owned frame, flags6, selectors, reserved fields, complete readable frame/FX
extents, authoritative MXCSR mask and new executable RIP/writable RSP. Legitimate
user edits to all GPRs, RAX, RIP/RSP, x87/SSE, mask and alternate-stack state are
accepted before one commit. Linux FIX_EFLAGS is merged; the current admitted
profile additionally rejects TF/RF/AC/IF/IOPL. Current per-thread FS/GS bases
survive handler changes; obsolete selector fields never supply MSR bases.
Malformed frames stage actual process shutdown139, not successful errno return.
Fatal default actions likewise stage owned shutdown; job control is unsupported.

The explicit RestoreUser action is allowed only on syscall15 with unchanged
thread bases and validated return mappings. The native callback installs every
user GPR/FX byte at phase1, preserving supervisor restoration data. Original
inactive installation remains phase0/2; emitter byte paths are unchanged.
