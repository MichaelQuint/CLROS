## Evidence

Core review found that Linux write takes a 32-bit descriptor argument. The
dispatcher now normalizes the low unsigned int and the fixture covers high-bit
stdout/stderr arguments. Primary reference: Linux
[write definition](https://github.com/torvalds/linux/blob/master/fs/read_write.c).
No Linux implementation source was copied.

The privilege plan follows the x64 architecture manuals: SYSCALL does not switch
RSP; RCX/R11 carry return RIP/flags. The emitted path changes to an owned stack
before using it and returns through an admitted IRETQ frame. Byte preparation or
readback cannot prove processor execution or ownership of page mappings.

Independent LLVM disassembly of the C#-emitted COFF fixture passes in
`artifacts/m16/transition-disassembly-r01.log`. It shows the GS stack switch,
register capture, MSR operations, FXSAVE64/FXRSTOR64, IRETQ, original fault jumps
and cleanup encodings. This object is a development byte fixture, not the EFI
artifact or an original compiler callback review. SS restoration supersedes it.

The corrected r02 object/disassembly include SS restoration, trap padding and a
separate CPL0 observation leaf for later independent original/live state checks.
`transition-r02.obj` SHA256:
`d745808ce63c7466edca92f9ecb495791b4d873252fc683fb1972ef45a86940e`;
`transition-disassembly-r02.log` SHA256:
`7b68e3af4396dff6e8f20be158c960745865a3d615c9b21827c7f4859b583b86`.
The observation leaf preserves RBX/RDI and records control registers, selectors,
CPUID, syscall/FS/GS MSRs and descriptor pointers into an owner-proven buffer.
It supplies no hardware authority or receipt by itself.

and service children. BootSequence owns pre-exit user-boundary preparation and
