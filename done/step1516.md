## What changed and why

Step1505's original native attempt returned readiness before the signal. An app
phase or delay cannot prove that the initial epoll wait blocked. Apply the
user-authorized expert's one-shot phase2 start gate and an explicit v2 controller.
The actor still performs write, tgkill and read as separate original syscalls;
actual EINTR, callback, empty recovery wait, fresh recovery byte and cleanup
remain mandatory. No retry or larger native wait is introduced.

POST `/__clros/signalrace/start` reuses the strict empty signal-request admission.
Only phase2 with positive waiter/actor identities accepts once; refusal does not
mutate the snapshot. The app waits for that request while detecting an early
waiter return/failure. Cancellation retains the existing abort, release, join,
signal acknowledgment, disposition restoration and descriptor cleanup order.
The separate signal-only path retains its original25ms delay.

V2 starts the pending race first, selects initial-armed, prepares the original
wait before starting short churn, observes churn pending/progress and sends one
start POST. Its21 selected samples bind to attempts-v2 and actual role streams.
Legacy selected/attempts-v1 and19-sample diagnostic readers remain explicit.
The private guest owner requires v2 plus a provisional original serial pending
wait before churn and again before start. This gate matches actual blocked
action3/status9, not Active/status1. Final immutable complete replay requires
`initial-wait < start-request-consumption < actor-write`; it does not force the
initial status response after the wait or start response before actor write.

The private Linux-native experiment borrows RunHttpAsync's actual strace Process.
It joins exact child/session/executable, held proc generations and thread pidfds,
one CPU/affinity, original normal policies, actual sleeping232/2500ms and exact
epoll/pipe identities before scheduling changes. Tracer FIFO2 and actor FIFO1
are checked again before the one start intent. Restore the surviving owned
tracer at phase4/finally; do not target an actor's recycled numeric TID after
release. Confirm original task death only after successful owned session stop;
always dispose and drain both logs, retaining the original failure.

Native signal-race qualification emits explicit v7. It requires selected-v2,
attempts-v2 and a complete bounded schedule-v1 journal in the existing hashed
Outputs inventory. Twelve records, or thirteen with optional actor retirement,
bind roles/generations/session/CPU, actual later sleeping wait observations,
unchanged pipe, policy readbacks, two rechecks, one start, successful tracer
restoration and confirmed original task exits. Tracer retirement cannot replace
restoration. Historical v5/v6 remain selected-v1, with attempts-v1 for v6;
ordinary v4 is unchanged.
