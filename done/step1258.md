# Step 1258 - Canonical asynchronous activation fixture and strict scheduling transcript

## Summary

Development #687/#733 adds the canonical M16-009 `Activation` input with
`env.CLROS_USER_IRQS=1`. The original eleven signal/fault packages retain their
exact bytes and IF-off protocols. This step changes tooling/tests/docs only;
native/kernel source remains at step1257. No IRQ, handler or guest has executed.

Two actual user threads are required by the emitted instructions. The parent
installs signal35 and an alternate stack, clones the child, seeds all fifteen
non-RSP GPRs, x87 controls, MXCSR, XMM0/15, DF and private FS/GS, then sets a
shared readiness word and spins in JMP $ without syscalls. A real user IRQ must
allow the child to run. The child checks its own TLS/GS and sends actual
tgkill(1,1,35). The handler verifies every saved GPR, RIP/RSP, flags, siginfo and
FP state, edits saved RIP/RAX, clobbers its own state and returns through syscall15.
The parent checks restored state, the red zone and actual child clear-TID before
its stdout witness and exit_group42. Both ending excursions must drain their
one-shot through the kernel checkpoint and complete genuine exit/reap lifetimes.

The fixture records complete instruction boundaries and per-worker syscall
stages, selectors/base/stack envelopes and DF policy. These include the child's
shared clone continuation, handler/restorer, initial argc/argv/env/auxv stack and
temporary PUSHFQ depth. An independent test decoder checks every emitted success
instruction; operand bytes and padding cannot become legal IRQ resume points.

The strict transcript uses the real two-generation FIFO schedule rather than a
fixed interrupt count. Each dispatch must finish with exactly one user IRQ or
ending-excursion drain, followed by its matching supervisor transfer. It checks
selected identity, complete syscall vectors/instruction continuations/results,
captured parent spin RAX/RIP, signal-before-handler ordering, user IF/DF/base/stack
envelopes, epoch and HPET clocks, actual clone readiness, both exits/reaps and final
restoration. Parent group-exit drain cannot invent a new process-clock advance.
No idle tick, blocked completion, extra worker or arbitrary ignored IRQ row is
accepted. Native limits allow 39..289 tail rows; synthetic controls exercise
39/51-row schedules with early entry, child, handler and post-sigreturn preemption.

## Why

The user IRQ source from step1257 needed a concrete input that cannot succeed
through cooperative syscalls alone. JMP $ can advance only through the checked
signal-context RIP edit. A canonical package and complete scheduling parser are
required before future native/guest evidence, while preserving every earlier
negative and disabled-path receipt.
