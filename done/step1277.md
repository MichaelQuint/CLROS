## Why

The retained, Linux-qualified NativeAotSuspensionSmoke worker trace `.2976`
blocks signals, unmaps its own 1,585,152-byte stack/TLS allocation, then exits0.
The original gateway rejected its now-unmapped RSP/FS before reaching exit60.
The independent old-production-DLL callback reproducer retains that failure in
`artifacts/runtime-linux-builder-r01/self-unmap-independent-review.log`.
Ordinary unmap/exit succeeds; self-unmap terminates InvalidReturn and a later
exit is rejected. The existing real thread service already treats inaccessible
clear-TID as best-effort EFAULT while committing exit; it needs no modification.

## Evidence

`actual-elf-tail-r01.log` independently reads the retained original ELF's RX
program header and bytes at virtual0x4648b7/file411831:
`B80B0000000F054831FFB83C0000000F05`. Its SHA256 remains
`F135EAC7774D92C9091C0A6954B915E60E403B80C50253FD396E2DD26370B8A1`.
Return RIP0x4648be is followed by XOR, move60 and syscall; final return RIP is
0x4648c8. The actual Linux trace's last four lines are retained alongside it.

Admission requires a page-aligned dynamic extent at/above4GiB, at most16MiB,
containing the complete RSP-8..RSP and nonzero FS, GS0, exact immutable RX code
and every removed page absent. The native callback additionally proves the
selected current generation, IRQ-off owner, full blockable mask and depth0.
Retained RIP/RSP/FS and post-XOR flags admit only offsets0/3/8 for IRQ images
and offset10/exit60/code0. AF alone is architecturally undefined after XOR.
Mapped-return admission remains the default for null/no-tail policies.
Tail state clears on terminal dispatch or failure and existing reap zeros gates.

A narrow read-only review found no core defect, then identified two concrete
consumer gaps. A first-row forged FS could establish its own tail baseline;
the new negative failed before the fix, retained in `forged-tls-r01`. ArmExit
now validates the ordinary live envelope before unmapping. IRQ RAX is also
bound to0 at offsets0/3 and60 at offset8, with an offset8 positive and wrong-RAX
negative. The final transcript-r04 fixture passes all five checks, including
old suspension/pool vectors and new tail/IRQ/error controls.
