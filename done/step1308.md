# Step 1308 - Bound silent QEMU startup and capture a recurrence

## Summary

Positive runs requiring `M03_EBS_RETURNED_SUCCESS` get a separate 30-second
startup deadline. `--startup-timeout` / `-StartupTimeoutSeconds` overrides it.
Expiry fails with exit 4 and `startup_timeout`; late markers cannot turn it into
success. A five-second best-effort QMP capture saves stopped registers, instructions
at RIP, stack words and up to 512 MiB physical RAM before existing owned-child cleanup.

## Why

The step1307 Matrix r04 failure spent 471 seconds after its last startup marker.
The source audit and 80 short replays of its exact pristine disk did not establish
a cause. Do not disable the firmware watchdog or change RNG behavior speculatively.

## Files changed

`tools/OS.QemuRunner/{Program,QemuCommandBuilder,SerialMarkerStateMachine,
QemuStartupDeadline,QemuStartupCapture}.cs`, `tools/OS.Tooling/{QemuSmoke,
QemuSmokeOptions}.cs`, the focused startup/runner host tests, and the existing
QEMU/diagnostics docs. EFI, kernel, guest and transcript contracts are unchanged.

## Tests run

- Host test project builds with zero warnings/errors; three focused startup
  checks pass (partial/late markers, workload budget, option validation).
- Runner control with unavailable QMP fails at the startup deadline, bounds the
  diagnostic attempt and confirms child termination (6.386 seconds).
- Forced two-second live timeout captures 268,435,456 RAM bytes plus CPU state,
  returns exit 4 / `startup_timeout` and confirms child cleanup in 2.811 seconds.
- The unchanged Matrix disk completes with the final runner in 24.057 seconds:
  all 147 ordered/unique markers pass, with no order violations or duplicates.
- Equal two-second startup/overall deadlines still capture before cleanup:
  exit 4 in 2.595 seconds, 256 MiB RAM, last marker `TEST_START m03.007`.
  Original PE header/link-map offsets locate image base `0xDAD9000`, phase 2,
  preparation checkpoint 35 and RIP `0xDADB112` in `ClearWithoutReferences`.
  This deliberately interrupted normal preparation; it is not the original hang.
- The existing late-marker timeout check and 14 serial parser checks pass;
  19 focused checks total. `repo check` and `git diff --check` pass.
