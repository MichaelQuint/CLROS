## What changed and why

The real socket guest needs its original instruction authority and observations

NativeAotSocketProgram reuses the reviewed bounded index parser with a distinct
CLROS_SOCKET_INSTRUCTIONS_V1 domain. Construction requires the exact selected
original package, current relevant raw sources, complete reviewed index digest
and every syscall continuation. The sealed lookup has no public constructor;
reports and synthetic/equal-count rows cannot construct authority. Concurrent
bounded single-link file snapshots reject aliases, invalid UTF8 and changed
reads. The two unchanged ELF modes share one exact index; their canonical package
arguments still differ. CLI socket-index is explicitly report-only; socket-program
requires sealed authority.

The existing combined EFI owner now observes actual retained source3 completion
after real network/clock/readiness mutation, once per generation/sequence. New
M16_012_WAKE records read process and kernel-table snapshots without completing
or otherwise mutating a wait. The worker emits M16_012_REPARK only after genuine
stolen-readiness repark with the next sequence and original deadline, or
M16_012_COMPLETE with the retained winner, actual return value and table clock.
The following original M16_008_RESUME must agree. Observer arrays derive their
capacity from the actual native worker inventory and remain image-resident.
These rows are source implementations, not guest-observed captures in this step.

NativeAotSocketGuest reuses original raw fd1 framing for sync/async stdout and
binds source3 calls, wake, repark, completion and resume. All active wait sources
require a new recorded wait before another resume; sequence continuity spans
futex/pipe/epoll. Already-won completion is retained past later clock advance.
Deadline completion may still collect fresh events; zero return requires actual
expired deadline evidence. Interrupted completion requires EINTR. Missing,
duplicate, orphan, noncanonical or inconsistent observations reject. Existing
call-parser consumers still reject source3 unless explicitly enabled.

The decoder intentionally returns value-only observations. PendingWaits can
include waits later retired by process exit; it is not a drained-process report.
Complete scheduler, signal, packet, parent and QEMU acceptance remain separate.
The socket_guest_orchestration_pending runner guard remains enabled.
