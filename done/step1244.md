## Why

The old syscall location precedes PCI/APIC; the threading consumer needs the
qualified timer owner afterward. The new default-off RunOwnedLinuxThreads gate
requires startup, stopped service, revoked firmware and actual APIC readiness.
Existing M16-005 through M16-007 keep their original placement and byte mode.
The shared admission prepares the concrete memory/descriptor owners before the
native driver binds them. Each M16-008 worker uses its own saved user image;
the old single gateway state is not begun or executed for that profile.

Native rows now retain all syscall arguments, RIP/RSP/flags/FS/GS, table time,
result and gate state. Separate rows record actual blocked completion,
supervisor confirmation and worker/resource binding. The existing exit, reap,
timer and drained cleanup records complete the tail. Global CPU/descriptor/MSR/
FP/stack readback follows the actual native owner return before READY/PASS.

The strict parser binds all 18 parent and 11 child calls to the canonical ELF,
dynamic Linux PID/TIDs/fds, distinct kernel generations, static stacks/FS,
blocked completions, clear-TID exit before join completion, off-stack reap and
the actual successor generation. Six supervisor confirmations require twelve
transfers; four blocked completions occur exactly once. The genuine relative
1ms timeout requires elapsed HPET nanoseconds from the table's admission time,
not an IRQ count. One through 128 bounded epochs are supported. Every unexpected,
duplicate, dropped, reordered or altered record fails parsing.

Full parent validation remains in the original entry point. The additive Linux
startup/service rows are validated and removed before the complete original
PCI/APIC inventory is checked. ARMED's user root must match M16-004 TABLES;
BOUND's kernel root must match the actual M16-004 READBACK.old root.

The compiled package writer uses CreateNew and never overwrites an existing
file. The runner holds its original read lock and verifies canonical bytes
before invoking native build/launch. Package creation or synthetic parser rows
provide no guest execution evidence.
