## Summary

## Why

SharpOS step197 at `39019fae88d402dfccdcae88c952b75dead36af7` is a useful
source reference for normal-called finally recovery and skipping the exited
clause in both passes. The independent reviewer narrowed admission to a plain
funclet whose own unwind recovers a root block with the same root address.
SharpOS lacks CLROS's complete saved-XMM/readable-stack/atomic-failure contract.
Its throwing enumerator/Dispose examples and NativeAOT8 output do not prove a
CLROS .NET10 call shape. No SharpOS code was copied.

The first CLROS NoInlining fixture compiled its normal finally inline in the
root. Applying the CLR MethodImpl NoOptimization bit `0x40` to this bounded root
made pinned ILC10.0.12 emit the required direct normal call and own-frame
funclet. The minimal enum has no named NoOptimization member; no BCL expansion
was needed.
