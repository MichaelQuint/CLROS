## Summary

Implement #95 with shared integration #606. The same allocation-free selector
validates the retained five-table directory in host tests and in a default-off

## Why

exit. Reuse original M03 storage and its lifetime rather than dereferencing embedded
firmware addresses or creating another copy owner.

## Failures

The first host build required `/unsafe` for the two shared pointer readers.
The initial transcript fixture used lowercase hex while the shared strict reader
requires uppercase; the guest writer and fixture were corrected together.
Initial publication attempts rejected the changed canonical project identity and
a forbidden using directive in the new no-stdlib source. The reviewed project
identity now uses the exact XML reader normalization, and the selector uses fully
qualified shared primitive calls. A temporary hash-edit replacement mistake caused
a tooling compile error and was repaired before publication. All failed logs remain.
Independent integration review found that the existing readback refreshes descriptor
comparison counters. The guest control now compares all 30 saved descriptor words
before invoking that readback, so it cannot repair and hide an input mutation.
