# Step 1710 - Compiler-owned M02 and live allocator source contracts

## Summary

Checked port-I/O, COM1 and panic-reporting fixtures now follow selected compiler
types, methods and bound calls instead of filenames or Compile-list positions.
The live allocator fixture uses compiler-selected profiles instead of its own
preprocessor. Independent review preserved the original safety oracles while
adding moved-source, inactive-partial and mutation controls.

## Why

Fast and Full share these source readers. Physical layout is not a contract:
moving a method or helper must not break validation or let the check miss it.
Expected ABI values, prerequisite gates, marker bytes, failure ordering and
negative controls remain independent of discovery.

and reviewed project admission. Required type identities replace arbitrary
Compile counts and adjacency. Public readonly struct checks also reject records.
Bound marker methods retain private/static/nongeneric/void requirements.
Complete caller discovery includes nested constructors, accessors and local
functions; panic readiness emission must have exactly its owned caller.

The allocator keeps its ten original contract cases, 27 ordered core predicates,
eight ledger vectors, fifteen mutation tuples and marker ownership. Actual
Diagnostic 00/10/11 profiles select source; invalid 01 rejects independently in
host options and the original MSBuild prerequisite predicate. Inspection views
are never concatenated compilation inputs. Three moved-method controls and
arbitrary filenames pass; extra bound callers and altered fallback behavior
reject. Original compact shape checks remain bounded oracles, not a general
semantic proof.

Raw exclusions use actual compiler documents, including wholly inactive
partials. They conservatively reserve containing declaration names and generic
arity across namespaces; active semantic checks retain exact qualified owners.
Formatter checks inspect branch witnesses and the union of byte-cast spans per
physical method. This does not enumerate every executable symbol combination.
Derived names/marker strings are cached by immutable document object identity,
without retaining witness trees. A selected declaration proves raw-document
inclusion directly; absent conditional owners still require witness discovery.
Same-path replacement controls reject stale snapshot reuse.
