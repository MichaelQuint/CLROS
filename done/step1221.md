# Step 1221 - Keep the timer frame on the existing no-stdlib surface

## Summary

Replace explicit interop layout attributes with naturally sequential fixed/ulong
fields in X64TimerInterrupt.Frame. The actual704-byte layout and every offset
remain unchanged under the five focused checks. This compatibility follow-up
does not install or execute the interrupt entry; #187/#721 remain open.

## Why

The explicit EFI project disables standard-library/framework references, and
the first-party minimal source has no StructLayoutAttribute/FieldOffsetAttribute
definitions. The frame needs no overlap or custom packing: its512-byte FX image
and remaining8-byte fields naturally express the required layout. Reuse that
existing field model instead of expanding the minimal runtime attribute surface.
Caller-supplied16-byte IST alignment remains separately required.
