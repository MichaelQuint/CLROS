# Step 1082 - Implement disabled single-finally admission and validators

## Summary

Issue #589 now has an actual selector and cleanup/continuation validators behind
the unchanged false execution switch. The containing typed catch is validated
and type-matched before selecting its one inner cleanup. Exact measured clause
geometry, root/funclet unwind rows, parent frame, exception identity and stamp
are required. The cleanup must write the stamp once before catch admission.
Both validators bind the bridge pointers, complete saved context, initialized
entry control snapshot, post-control fields, explicit root and retained object.
Only the measured catch's RIP/RBX changes are permitted in its post-context.
The legacy simple-catch implementation and bridge bytes are unchanged.

## Why

The first native candidate in step1081 established the concrete two-clause
fixture. These guards implement that bounded contract while keeping execution
disabled pending final native callback, frame and stack review.
