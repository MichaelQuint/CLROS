needs bounded partial-body, slow-response and cancellation stimuli before the
full repeated-service acceptance can be exercised.

- ServiceLifecycleExercise.cs: fixed32KiB patterned echo,512KiB patterned stream

  Streams remain caller-owned. Wait cancellation drains; interrupted I/O
  propagates after accounting. A wait requires a cancellable lifetime.
- MinimalApiService/Program.cs: bind those routes only for matched v2 selection;
  refuse stop while a lifecycle request worker is still active. Existing v1
  endpoint selection remains separate.
- NativeAotServicePackage.cs: explicit lifecycle parameter selects matched v2
  argv/settings. Default v1 and crossed-mode rejection remain checked.
- KestrelConnectionLifecycleTests.cs, the host project link and service package
  tests: partial reads/hash, slow-output concurrent progress, cancellation/reuse,
  malformed/truncated input and strict package mode rejection.
