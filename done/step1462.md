## Why

The parent blocks in actual epoll. The child writes one byte, directs signal10,
then consumes the byte before parent dispatch. The parent reparks with a new
wait sequence; its pending signal completes that wait before Park commits.
The real handler/restorer runs, then a fresh write/epoll/read succeeds. This
extends step1461's pipe-read case through the epoll wait owner.

The first actual attempt exposed the documented socket-only epoll target
restriction. Bounded anonymous pipe admission now derives readiness from existing
pipe storage and counts. It reuses descriptor identity, refresh, edge bookkeeping
and last-reference cleanup. A genuine borrowed operation retains the original
description across fd close/reuse; its final release removes the watch.
