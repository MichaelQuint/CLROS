storage. Its entire extent must be mapped supervisor RW. The fixed diagnostic

bypasses the diagnostic network scheduler, which would otherwise borrow the
same cooperative pool as Linux workers. Restored syscall and idle boundaries
pump real RX/TX, TCP timers, hardware-clock wait deadlines and epoll readiness.
Empty infinite epoll no longer triggers the old no-work stop4 path.

After worker release, remaining descriptors close before normal transport drain,
full real TIME-WAIT, scrubbed table retirement and descriptor end. Failed native
execution uses the separately bounded abort path. Socket completion markers are
emitted only after the outer NIC stop/reset/DMA cleanup succeeds. These are
implemented paths, not guest-observed behavior in this step.

New NativeAotSocketPackage creates canonical sync/async V1 packages from the same
unchanged retained ELF. It checks nine current relevant raw sources, immutable
original receipt, all32 retained outputs, produced app DLL/object and original
producer DLL. Output/source inventories are bounded; linked, missing, altered,
extra or substituted inputs reject. Fresh publication flushes an owned temporary
and uses no-overwrite rename below artifacts. External Linux native inputs remain
original receipt identities; unavailable files were not rehashed on Windows.

QEMU rejects the new leaves with socket_guest_orchestration_pending while their
original instruction index, peer and strict transcript remain unwired. It cannot
inherit the older scripted M07 TCP package/protocol as native socket authority.
