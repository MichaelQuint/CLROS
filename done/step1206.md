# Step 1206 - Linux descriptor and pipe host foundation (in progress)

## Summary

Implemented one retained, single-owner descriptor service and a caller-buffer
nonblocking pipe ring for M16-007/#685. The build and 22 independent host cases
pass. This is an implementation checkpoint, not issue or guest qualification.

## Why

The unchanged pinned runtime uses descriptor duplication/flags and creates a
signal pipe before stdout. These services must exist before the scheduler and
signal slices. Keep Linux fd/errno semantics separate from OSHost handles, and
commit ownership/cursors only after successful user copies.
