## Files changed

- MinimalApiService.csproj adds direct static libc mmap/munmap imports.
- ServiceLifecycleExercise owns at most32 one-MiB mappings in256 stack bytes.
  It records ownership before touching bytes, fills/checks every retained byte,
  and attempts every release in finally. Only ENOMEM is expected; other errors,
  corruption or release/recovery failure reject. A fresh one-MiB mapping is
  filled/checked/released before reporting. Reporting allocations happen after
  release. GC commitment is captured while native ranges remain retained.
- Program emits separate CLROS_SERVICE_NATIVE_BEGIN/END records after managed
  measurements, before listening and after drain respectively. V1 skips both.
- NativeAotServicePublisher seals the three changed app inputs. The original
  image/index/program pins remain unchanged and reject these changed sources;
  they may be refreshed only after a genuine new original publication/index.
- QemuTranscripts.NativeAotService.Gc adds copied native values and validates
  unique fd2 records, order, exact32MiB attempt cap, aligned positive retained
  bytes below the cap, errno12/quota1, exact releases and one-MiB recovery.
  Explicit native plus contemporaneous GC commitment must fit the kernel peak.
- StartupReplayTests adds an independent negative/boundary case and preserves
  existing GC controls with native records present. Canonical docs/owned scope
  and M16-016 current evidence are consolidated.
