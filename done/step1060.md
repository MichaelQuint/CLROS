## Summary

Extends #574's existing metadata decoder with `LookupFunction`, selecting a
zero-based listed function through the same validation and decode path as PC
lookup. Original storage, module authority and the complete immutable snapshot
are revalidated before index bounds; invalid indices return zero payload.

## Why

Review of #579 found that a handler inside a supplied code contribution can
still belong to an intervening root method. The pinned NativeAOT runtime assigns
funclets to the nearest preceding root entry. Indexed access lets the EH leaf
check that relationship without reading private storage or adding a PE parser.
The relationship check itself remains #579 work.
