# Step 1034 - Reusable focused host fixture command

## What changed and why

Add scripts/run-host-tests-focused.ps1 to run explicitly selected original host
fixture files through their existing module initializers. The complete harness
starts every module before Program.cs, so even one assertion repair previously
required a copied ad hoc project or a long complete run. This command generates
an isolated project under ignored artifacts, retains the normal framework and
project references, and records selected source hashes, native commands/exits,
logs and a focused-only result. It does not modify fixture bodies or the full
harness. Inputs are explicit basenames; Program.cs and traversal are rejected.

- docs/host-requirements.md

  reservation directory containing the latest step1033. The running collector
  checkout was not modified.
