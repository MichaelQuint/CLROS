# Step 1135 - Integrated APIC and MSI-X development profiles

## Summary

Integrates #113/#114 under #619 after step1134. The default-off APIC profile
executes masked setup after real firmware exit. The separate MSI-X profile
observes one returning interrupt and completes the existing bounded TX queue
transaction. Strict publication, focused checks, native review and real guest
development captures pass. Full-host batch qualification is still pending;
all three issues remain claimed and unaccepted.

## Why

Host contracts alone did not connect retained mappings, hardware identity,
temporary IDT authority, interrupt observation and DMA lifetime. This integration
tests that complete bounded path without introducing a general IRQ framework.

## Evidence

Current production inputs passed strict wrapper publication/native verifier and
real QEMU/OVMF development captures: APIC r04 has 104 records, MSI-X r04 has
157, and the ordinary r01 regression has 79. The final r05 captures refresh
provenance after correcting the tooling inventory order. Exact commands are in
`docs/efi-build.md`; logs/images/artifacts use the matching `m05-*-final-r05`
prefix. Original failed and passing development captures are retained.

The MSI-X r04 capture records one interrupt, no spurious delivery, ISR7 bit zero
set before EOI and clear afterward, IF set only at the captured native wait RIP,
IF clear on return, exact original IDTR restoration and one used-ring acquire.
MSI-X masking, observed reset and bus-master disable precede backing release.
This is completion of one experimental TX descriptor, not packet-delivery proof.

`irq-native-review-r04` contains COFF disassembly, unwind data and association of
all 790 method extents with the linked PE. 711 instruction streams match accepted
polling evidence after resolved-address normalization. Targeted changed-path
review covers Win64 preservation, callback bindings, bounded stack allocations,
temporary IDT integrity, interrupt-before-acquire and mask/reset/disable-before-
release. It is not a claim that every instruction was manually reviewed.
`manual-review.json` and `stack-review.json` record a conservative 10,168-byte
diagnostic bound and 4,968-byte fault bound within the owned 32 KiB stack. Raw
leaf disassembly is in `apic-leaf-review-r01`. No AVX/x87 requirement is added.

`apic-msix-capture-disk-association-r01.json` independently validates primary and
backup GPT CRCs, FAT copies and exact EFI payload bytes for development captures.
Final r05 captures all pass and `apic-msix-capture-disk-association-r05.json`
confirms their exact image payloads. `apic-native-final-association-r05.json`
confirms the final IRQ PE, COFF and ILC map are byte-identical to the reviewed r04
inputs. All 618 raw source-closure files match current files for all three final
captures, closure SHA-256
`4d1db8d471b59b10821a11f8d6eb73da3b687a1afd7da0bccd9938f0821a67b3`.
The MSI-X development PE is 416,768 bytes, SHA-256
`deaf492ad7160acb10b24ddb0c9e3c9dad7e62b38c2ea31ebbdb77e7052399b8`.

IOAPIC revision evidence: the current QEMU reports version 0x20. QEMU's primary
v10.0.0 `hw/intc/ioapic.c` supports 0x11/0x20 with the existing register window;

not inferred from the executable version. No reference code was copied.

## Failures

Preserved failures were corrected before final qualification:

- Initial strict publication rejected a project hash computed using a different
  XML loader. Recomputed with the canonical admission XmlReader contract.

  with focused positive/rejection controls; r03/r04 pass.

  writable UC range then failed (`InvalidRange`, preparation checkpoint 7205).
  Reverted grouping, retained four individual Virtio pages and centralized the
  capacity at 35. Interrupt r04 passes without weakening single-page UC rules.

  prerequisites and the wrong BAR/DMA helper name. Exact active syntax/caller
  checks and negative controls now pass. Two incorrect focused selection commands
  selected no fixtures; the explicit legacy fixture/case runs above passed.
- Contract audit r01 found the APIC switch outside the sorted reviewed inventory.
  Corrected its position; r02 passes. This changes tooling inventory order only.
