# Step 1487 - Frame bounded persistent quota HTTP prefixes

## Summary

Continue the same #737 owner and WIP PR790. Integrate the tandem subagent's
two-file value-only HTTP framing proposal. Parse every sequential complete
request/response and retain one explicitly incomplete final suffix. Positive

## Why

The quota peer uses persistent control traffic, header-only cancellation and an
intentional 64-of-32768-byte echo body. A whole-stream single-exchange reader
cannot truthfully frame those bytes. Consumed offsets and incomplete suffixes
must precede sample and original packet joins.
