after scrub before reuse. Failure with unresolved execution retains backing.

larger guarded arena. A new host control checks four 64-byte spans in 256 bytes,
private scrub, retained other-worker bytes and unchanged adjacent bytes.

generation, timeout/cancellation winner, segment owner, reuse and restoration
