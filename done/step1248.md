## Why

The pinned upstream NativeAOT runtime installs real SIGSEGV/SIGFPE/activation
actions, and System.Native installs its signal worker/pipe handlers before
Hello. Successful registration must preserve state rather than discard it.
Per-thread stacks must not become process-global or survive a reaped generation.

LinuxSignalServices owns one noncopied supervisor metadata block with exact
32-byte kernel action and 24-byte stack_t representations. The existing thread
owner authenticates each real current generation and attaches exact matching
user-copy capabilities. Attachment rejects overlapping process/futex/descriptor/
worker storage and late/duplicate attachment. Thread publication binds signal
metadata before exposing the actual created worker; failed creation unwinds
that binding. Actual off-stack reap clears it. Release detaches before End
scrubs the signal owner; application backing remains separately owned.

Action registration masks unsupported flag bits and unmaskable signals, allows
queries for SIGKILL/SIGSTOP but rejects changing their actions, and preserves
the committed action if old-action copyout fails. Alternate-stack registration
implements disabled/query/current-stack state, active-stack EPERM, size ENOMEM,
flag validation and SS_AUTODISARM registration semantics. Padding is zero on
output. A valid update likewise survives old-stack EFAULT. Registration stores
user handler/restorer/stack values without invoking or leasing them; delivery
must separately admit actual user mappings, frames and return state.

The gateway explicitly routes syscall13/131 to the actual thread owner. No
pending signal, delivery, user callback or rt_sigreturn is accepted by this
startup slice. Existing masks remain in the thread slot. Native allocation,
M16-009 selection, interrupted waits and actual delivery are unfinished.
